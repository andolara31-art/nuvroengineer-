# Imagen editorial

## Portada actual: negocios ticos + tecnología útil

- Archivos: `nuvro-negocio-cr-tecnologia-v1-720.webp` y `nuvro-negocio-cr-tecnologia-v1-1080.webp`.
- Dimensiones: 720 × 960 y 1080 × 1440 píxeles.
- Creada con la herramienta integrada de generación de imágenes para representar un pequeño negocio tropical con QR, punto de venta y teléfono de gestión.
- Es una escena editorial ficticia inspirada en negocios de Costa Rica. No representa a un cliente, comercio o proyecto real de NUVRO.
- La leyenda visible y el texto alternativo indican que fue generada con IA.
